# 工作流详细指南

## 完整执行路径

```
接收原文
  │
  ▼
S0: 文体诊断 ──→ 确定文体/读者/模式
  │
  ▼
S1: 特征扫描 ──→ 运行 5 维检测 + 事实核对
  │               输出检测报告
  ▼
S2: 结构改写 ──→ A1→A2→A3→A4→A5→A6（按此顺序）
  │
  ▼
S3: 节奏手术 ──→ B7→B8→B9→B10→B11
  │
  ▼
S4: 词汇微调 ──→ C12→C13→D1→D2→D3
  │
  ▼
S5: 校验 ──────→ 对比扫描 + 读出声 + 逆向读 + 自查清单
  │
  ▼
  交付
```

---

## S0：文体诊断模板

在处理任何文本前，用以下模板做诊断：

```
文体：           [学术论文 / MBA论文 / 商务报告 / 政府文书 / 通用文章]
目标读者：       [导师/评审委员会 / 高管/客户 / 公众 / 同行]
字数：           [XX字]
改写目标：       [降AIGC率 / 去AI味 / 润色提升 / 通过检测]
期望模式：       [论文模式 / 商务模式 / 通用模式]
难度估计：       [轻改(<40% AI信号) / 中改(40-70%) / 深改(>70%)]
```

**模式选择依据**：
- 如果文本包含"参考文献"、"第X章"、摘要/关键词 → **论文模式**
- 如果文本包含"报告"、"建议"、"调研"、公司名 → **商务模式**
- 如果文本是博客/文章/邮件/通用叙述 → **通用模式**

## S1：特征扫描模板

### 5 维扫描

对原文逐项扫描，输出检测报告：

```
═══ 5维检测报告 ═══

[D1 句长波动]
  句子数: XX | 均值: XX字 | 标准差: XX | CV: X.XX
  短句(≤10字): X.X% | 长句(≥45字): X.X%
  邻句跳跃均值: X.X
  判定: [正常/AI信号/严重AI信号]

[D2 段落波动]
  段落数: XX | 均值: XX字 | CV: X.XX
  段首模板重复: [无/≥3段相同/≥5段相同]
  判定: [正常/AI信号/严重AI信号]

[D3 词汇指纹]
  AI高频词命中: [词1, 词2, ...] (XX个)
  模糊归因命中: [XX处]
  抽象名词堆叠: [有/无]
  中文句法模式: [模式21/22/23/24/25命中情况]
  判定: [正常/AI信号/严重AI信号]

[D4 连接词密度]
  段首连接词 %: X.X%
  逻辑连接词密度: X.X‰
  三连段模式: [有/无]
  判定: [正常/AI信号/严重AI信号]

[D5 空转大词]
  主题升华: [XX处]
  笼统结论: [XX处]
  无来源断言: [XX处]
  判定: [正常/AI信号/严重AI信号]

═══ 总体评估 ═══
  AI信号强度: [轻/中/重]
  优先处理: [列出最严重的前3个问题对应的手法编号]
  推荐手法组合: [如 A1+A2+B7+D2]
```

### 事实核对清单

对以下内容逐项核对（不可跳过）：

1. **引用核对**：每个"作者(年份)" → 真实存在吗？
2. **数字核对**：每个百分比/金额/统计值 → 有来源吗？
3. **断言核对**：每个因果断言（"A导致B"）→ 有证据吗？
4. **结论核对**：核心结论 → 是原文就有的还是 AI 制造的？

**凡是无法核实的，标注"该指标/数据需要进一步核实"**，不要伪造来源。

## S2：结构改写执行模板

### 手法 A1：替换骨架

```
□ 检查开头：是否是"定义→背景→意义"或"随着X的发展"结构？
□ 如果是→改为"具体案例+具体问题+方法"
□ 案例从哪里来：①原文中已有的具体事例 ②原文数据 ③如果原文都没有，用方法论替代
```

### 手法 A2：删除升华

```
□ 扫描最后一段/结论段
□ 标记所有"时代/趋势/浪潮/意义/价值贡献/深远"类表述
□ 删除并替换为具体发现/待解决问题
```

### 手法 A3：削减 30%

```
□ 检测"全面覆盖"段落（篇幅长但无立场）
□ 标记可删除的内容：①与核心论点无关的背景 ②众所周知的定义 ③重复的论证
□ 目标：缩减原文约 30%
□ 注意：不要删除数字/数据/引用
```

### 手法 A4：加反例

```
□ 检查论证链条：是否全是"A→好结果"的正面叙述？
□ 如果是→加入：①限制条件（"这只适用于..."）
  ②反例（"但在X条件下不成立"）③未解决的问题（"目前尚未解决的是..."）
```

### 手法 A5：替换枚举

```
□ 标记所有"首先/其次/最后"、"第一/第二/第三"、"一是/二是/三是"
□ 检查这些点之间：是并列关系还是因果关系？
□ 如果是并列→改为因果关系链（A→B→C）
□ 如果确实是并列→把"第一/第二"改为内容本身的承上启下
```

### 手法 A6：注入不可替代的细节

```
□ 标记所有"许多/一些/某些/有的"、"专家/学者/业内人士"
□ 如果有原文数据→用数据替换
□ 如果没有→用"我们观察到的具体现象"替换
□ 注意：不要编造数据/引用
```

## S3：节奏手术执行模板

### 手法 B7：长短句手术

```
目标指标：
  句长 CV 目标 ≥ 0.45（最好 0.50-0.65）
  短句(≤10字)占比 ≥ 12%
  邻句跳跃 ≥ 15

操作：
  ① 在每 3-5 个中等句子后插入 1 个极短句（≤10字）
  ② 在每 5-8 个句子中让 1-2 个句子扩展为 45+ 字
  ③ 扩大相邻句子的长度差异
```

### 手法 B8：破三连

```
□ 标记所有三重排比（三个分句、三个比喻、三个例子）
□ 操作：保留其中最有信息量的一个，其他两个删除或合并成一个
```

### 手法 B9：加插话

```
□ 在关键论断前加入"老实说"、"说白了"、"按经验"、"说实话"（通用模式）
□ 在学术模式中替换为"值得注意的是"、"需要说明的是"、"严格来说"（适度）
```

### 手法 B10：换视角

```
□ 将部分被动句改为主动句
□ 将部分"研究发现"换为"从X数据来看"或"本研究的追踪数据显示"
□ 在通用模式中可使用"我/我们"
```

### 手法 B11：去连接架

```
□ 遍历每个段落的第一句
□ 标记以"此外/另外/同时/而且/然而/因此"开头的段落
□ 删除开头的连接词，用内容本身承上启下
□ 目标：段首连接词 ≤ 15%
```

## S4：词汇微调执行模板

### 手法 C12：培养个人偏好

```
□ 统计全文动词/形容词，是否有明显的词汇均匀分布？
□ 选择 2-3 个词在全文中重复使用（如"改善"出现 4-5 次）
□ 注意：不要过度（同一个词间隔使用，不要连续出现）
```

### 手法 C13：降低形容词密度

```
□ 全文搜索"重要的/关键的/显著的/极大的/极高的/非常好的"
□ 删除 70% 以上，并用具体事实替代
□ 如果无法替换→直接删除
```

### 手法 D1：收窄术语

```
□ 标记所有"构建体系/打造生态/重塑格局/创新范式/赋能体"
□ 用"我们具体做什么"替换
```

### 手法 D2：替换 AI 高频词

```
□ 运行 AI 高频词清单（SKILL.md 中的三档优先级）
□ 高优先级词 100% 替换
□ 中优先级词 80% 替换
□ 低优先级词视上下文替换
```

### 手法 D3：四字格调整

```
□ 标记连续的四字格/三字格排比
□ 拆散为长短不一的叙述
□ 注意：论文中的固定术语（如"深化改革"）不能拆
```

## S5：校验执行模板

### 1. 改前改后对比

对原文和改后文分别运行 5 维扫描，输出对比报告：

```
═══ 对比报告 ═══
                        改前      改后      变化
句长 CV                  X.XX      X.XX     [+/-X.XX]
短句占比 %               X.X       X.X      [+/-X.X]
段落 CV                  X.XX      X.XX     [+/-X.XX]
段首连接词 %             X.X       X.X      [+/-X.X]
空转大词                  X         X        [-X]
AI高频词命中              X         X        [-X]
"的"字密度              X.XXX     X.XXX     [+/-X.XXX]

共 X 项指标：X 改善 / X 退步 / X 持平
方向：[正确/需要调整]
```

### 2. 信息保全核对

```
□ 所有数字是否与原文一致？
□ 所有专有名词是否与原文一致？
□ 核心结论是否未被改变？
□ 引用是否未被编造或删除？
```

### 3. 读出声检查

朗读改后文本，标记所有"读起来怪"的地方，重新修改。

### 4. 逆向读

从最后一句读到第一句，检查每句单独是否成立。

### 5. Final 自查清单

```
□ 没有 AI 高频词残留
□ 没有升华/拔高
□ 有反例或限制条件
□ 句子有长有短，有呼吸感
□ 段落有长有短，不规整
□ 段首连接词不密集
□ 有个人化的词选择
□ 读出声自然
□ 信息保全（数字/专名/结论/引用全在）
□ 改前已备份
```

## 不同 AI 信号强度的处理策略

### 🔴 高风险 (>70%)：深度改写

- 必须执行：A1 + A2 + A3 + A5 + B7 + D2
- 建议执行：A4 + B8 + B11 + C13
- 预计：改前备份；多轮迭代；改后做对比
- 每轮重点：第一轮骨架；第二轮节奏；第三轮词汇

### 🟡 中风险 (40-70%)：针对性优化

- 必须执行：A2 + B7 + D2 + D3
- 建议执行：A4 + B8 + B11
- 预计：一轮改写 + 一轮校验

### 🟢 低风险 (<40%)：细节润色

- 必须执行：D2 + C13
- 建议执行：B9 + C12
- 预计：快速过一遍即可
