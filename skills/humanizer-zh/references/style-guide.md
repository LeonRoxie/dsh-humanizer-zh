## 1. "的"字使用规范

"的"字密度是中文文本最重要的统计指纹之一。

### 密度目标区间

| 模式 | 目标密度 | 说明 |
|------|---------|------|
| 学术论文 | 0.045–0.065 | 需要一定修饰但不要过载 |
| 商务报告 | 0.040–0.060 | 略低于学术 |
| 通用写作 | 0.035–0.060 | 口语化更低 |
| AI 侧特征 | < 0.040 或 > 0.070 | 检测器敏感区间 |

### 操作规则

| 规则 | 示例 |
|------|------|
| 冗余"的"删除 | "重要的关键的决策" → "关键决策" |
| 补必要"的" | "分析发现问题" → "分析发现的问题" |
| 区分"的/得/地" | "快速的跑"→"快速地跑"；"跑的很快"→"跑得很快" |
| 属性修饰不要"的" | "核心能力" ✓；"核心的能力" ✗ |
| 固定搭配不加"的" | "越来越多" ✓；"越来也越多" ✗ |"越来越多"的" ✗ |

## 2. 中英文混排规范

来源：humanize-mba-text-skill

### 空格规则

| 规范 | 正确 | 错误 |
|------|------|------|
| 中文与英文之间加空格 | "MBA论文写作需要关注 AI 痕迹问题" | "MBA论文写作需要关注AI痕迹问题" |
| 中文与数字之间加空格 | "2023 年的研究表明" | "2023年的研究表明" |
| 数字与百分号之间不加空格 | "15%" | "15 %" |
| 全角符号两侧不加空格 | "（AI）写作" | "（ AI ）写作" |
| 中文括号用全角 | "（具体数据）" | "(具体数据)" |
| 英文括号用半角 | "r=0.42(p<0.05)" | "r=0.42（p<0.05）" |

### 引号规范

- 中文文本中用全角引号：" " （）
- 英文术语引用用半角：`"machine learning"`
- 引号内中文用全角，英文用半角

## 3. 学术写作规范

来源：humanize-mba-text-skill + humanizer-formal

### 数据溯源模板

```
根据[来源/年份/方法]，[指标]为[具体数字]。
```

**示例**：
```
根据2023年12月开展的员工满意度问卷调查（N=120，5分制李克特量表），
员工满意度均值为3.8分，与2022年（3.5分）相比提升0.3分。
```

### 引用格式

- 中文引用：作者（年份）指出/研究发现/认为
- 英文引用：Author (year) found/suggested/demonstrated
- 引用必须可核实：如果无原始来源，标注"需要进一步核实"

### 章节结构原则

| 章节 | 字数建议 | 节数建议 |
|------|---------|---------|
| 第1章 绪论 | 3,000–5,000 | 4–5 节 |
| 第2章 理论 | 4,000–6,000 | 3–4 节 |
| 第3章 分析 | 8,000–12,000 | 4–5 节 |
| 第4章 对策 | 6,000–10,000 | 4–5 节 |
| 第5章 结论 | 1,500–3,000 | 3–4 节 |
| 总计 | ≥ 30,000 | — |

## 4. 文体区分

### 学术论文模式

**"人味"的定义**：可证伪的锐利论断 + 结构化论证 + 充分证据链

| 该要的 | 不该要的 |
|--------|---------|
| 精确数字 + 来源 | 模糊的"许多/一些/大量" |
| 可验证的引用 | "有研究指出/专家认为" |
| 受限条件的结论 | 绝对的"证明了/解决了" |
| 诚实的局限性 | "完美的/完整的/全方面的" |
| 个性化的写作用词 | "赋能/闭环/抓手" |

### 商务报告模式

**"人味"的定义**：具体案例 + 真实数据 + 可操作的结论

| 该要的 | 不该要的 |
|--------|---------|
| 具体企业/产品名 | "某企业/一家企业" |
| 时间+地点+人物 | "最近/不久前/有人" |
| 数字+趋势+对比 | "显著提升/明显改善" |
| 个人判断+理由 | "是重要的/是关键的" |

### 通用文章模式

**"人味"的定义**：个人体验 + 具体观点 + 自然口语节奏

| 该要的 | 不该要的 |
|--------|---------|
| "我"、"我们" | 无主语被动句 |
| 个人经历 | 抽象概括 |
| 口语化表达 | 书面语堆砌 |
| 观点的"偏见" | 客观中立的全面覆盖 |

## 5. 负面清单（语体门禁）

来源：aigc-humanizer style-guide

论文模式中禁止出现以下口语化/网络化表达：

| 类别 | 禁止词 |
|------|--------|
| 网络用语 | 懂了/懂了/讲真/真的真的/绝了/yyds/YYDS |
| 过度口语 | 话说/那啥/就是这么牛/牛X |
| 公众号体 | 惊了/万万没想到/看完我震惊了/再也不 |
| 过度谦卑 | 浅谈/粗浅/拙见/不成熟的想法 |
| 营销腔 | 重磅/独家/首发/必看/建议收藏 |

通用模式中鼓励适度口语化，但上述"营销腔"永远禁止。

## 6. 正向写作目标

来源：整合

| 方向 | 具体做法 |
|------|---------|
| **具体化** | 把"企业"写成"XX公司生产部"；把"有些人"写成"3个车间主任" |
| **数据化** | 把"效率提升"写成"订单处理时长从5天变成2天" |
| **个性化** | 保留 2-3 个作者偏好词；保留独特但不完美的句式 |
| **结构不规整** | 长短段交替；允许单句段；段首换花样 |
| **真实感** | 写"我们试过但没成功"而不是只写成功；写"这个问题目前没有完美答案" |

## 7. Final Check 清单

来源：aigc-humanizer (12条自查) + ai-patina (S5 check) + 整合

**改前备份清单**：
- [ ] 改写前已保存原文备份（如需回退）
- [ ] 确认信息点清单已冻结

**内容保全清单**：
- [ ] 所有数字是否原样保留？
- [ ] 所有专有名词是否原样？
- [ ] 结论/论点是否被改变？（内容不变，措辞可变）
- [ ] 引用/来源是否被编造或删除？
- [ ] 并列项数量是否减少？（不能减少）

**风格清单**：
- [ ] "的"字密度在目标区间内
- [ ] 句长 CV ≥ 0.45
- [ ] 段首连接词 ≤ 15%
- [ ] 无 AI 高频词残留
- [ ] 无升华/拔高
- [ ] 有反例或限制条件
- [ ] 读出声时没有"读起来怪"的地方
