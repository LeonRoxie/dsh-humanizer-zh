# Humanizer-ZH —— 中文文本人性化综合技能

整合自 5 套开源去 AI 方案的最佳实践：
[stephenlzc/humanize-mba-text-skill] · [swaylq/humanize-chinese] · [Rain13Sad/ai-patina] · [jiutianxvanyin/humanizer-formal] · [ycc77cn/aigc-humanizer]

## 核心理念

> **检测器不读含义，只量可预测性。** 所以修复不是"换更高级的词"，而是"离开模型最可能走的路"——人类已经在那条路之外了，因为人类有具体经验、真实观点和刻意不说的事情。

本技能的信条：
- **手艺优先，而非规避。** 降低检测率是文本变好的副产品，而非目标。
- **结构 > 词汇。** 改骨架比换词有效 10 倍；骨架不变，换再多词也没用。
- **证据层不可伪造。** 编造引用是 AI 最强烈的信号，没有改写能抹去——事实核对是不可协商的步骤。
- **文体敏感。** 学术写作的"人味"是可证伪的锐利论断，而非口语化——把论文改得像公众号是另一种失败。
- **禁止输出"AI 概率分数"。** 报告可解释的指标；拒绝产生一个假装是测量结果的数字。

## 工作流概述

```
S0: 文体诊断 ──→ 确定文体/读者/身份
S1: 特征扫描 ──→ 5 维度 AI 指纹检测 + 事实核对
S2: 结构改写 ──→ 骨架替换/删除升华/削减30%/加反例/替换枚举 (A1-A5)
S3: 节奏手术 ──→ 长短句/破三连/加插话/换视角/去连接词架 (B7-B11)
S4: 词汇微调 ──→ 培养偏好/降低形容词密度/收窄术语 (C12-C14)
S5: 校验 ──→ 改前改后对比 + 读出声检查 + 逆向读
```

**顺序不可逆。** S4 在 S2/S3 之后，没有任何"润色"步骤放在最后——那会把手术磨平。

## 5 阶段工作流 (S0–S5)

### S0: 文体诊断

在处理任何文本之前，先确定：

1. **文体**：学术论文 / MBA论文 / 商务报告 / 政府文书 / 通用文章 / 营销文案
2. **目标读者**：导师/评审 / 高管/客户 / 公众 / 同行
3. **"人味"程度**：学术（可证伪的论断+结构化） / 商务（具体案例+数据） / 通用（个人体验+观点）

> 这一步搞错，后面全错。学术论文的"人味"定义和博客完全不同。

### S1: 特征扫描

对所有文本运行以下 5 维扫描。每个维度的详细规则见 [references/detection-rules.md](references/detection-rules.md)。

| 维度 | 扫描项 | 典型 AI 信号 |
|------|--------|-------------|
| **D1 句长波动** | 句长均值/标准差/CV；短句占比 %；邻句跳跃 | CV < 0.40 太均匀；短句 < 12%；无大跳跃 |
| **D2 段落波动** | 段落长度均值/CV；结构指纹 | CV < 0.25 段落等长；段首模板连续 ≥3 段相同 |
| **D3 词汇指纹** | AI 热词命中表；抽象名词密度；排比结构 | → 见下方 AI 高频词清单 |
| **D4 连接词密度** | 段首连接词 %；逻辑连接词总数 | 段首连接词 > 30% 是 AI 信号 |
| **D5 空转大词** | 升华句/宏观叙事/笼统结论 | "时代/趋势/浪潮"、"至关重要"、"综上所述" |

**目标值（论文模式）：**
- 句长 CV ≥ 0.45（目标 0.50–0.65）；短句占比 ≥ 12%
- 段落 CV ≥ 0.40；段首连接词 ≤ 15%
- 空转大词：0 个
- "的"字密度：0.045–0.065（自然落点区间）

**事实核对（不可跳过）：**
- 编造引用是最强烈的 AI 信号，没有改写能抹去
- 检查所有"作者(年份)指出/认为"引用是否真实存在
- 检查所有数字/百分比/排名的来源是否可核实
- 无法核实则标注"该指标需要进一步核实"

### S2: 结构改写（70% 的工作量）

骨架优先。骨架不变，换再多词也没用。

执行手法：**A1 → A2 → A3 → A4 → A5**（按此顺序）

> 每个手法的详细说明及实例见 [references/rewrite-moves.md](references/rewrite-moves.md)

| 手法 | 操作 | 修复什么 |
|------|------|---------|
| **A1 替换骨架** | 定义→背景→意义式开头替换为具体案例+问题+方法 | 教科书式开头 |
| **A2 删除升华** | 删除最后一段的拔高/升华/展望 | 强迫式结论升华 |
| **A3 削减 30%** | 删除面面俱到的全面覆盖，保留有立场的内容 | 无立场的全面覆盖 |
| **A4 加反例** | 在自我确认的论证中补充反例或限制条件 | 自我确认式论证 |
| **A5 替换枚举** | 把"第一/第二/第三"改为有实际关系的段落连接 | 无逻辑关联的枚举 |

### S3: 节奏手术（句子级）

目标是让文本"呼吸"，而不是换更花哨的句子。

| 手法 | 操作 | 修复什么 |
|------|------|---------|
| **B7 长短句手术** | 在均匀的句子中插入极短句（≤10字）和长句（≥45字） | 句子长度均匀 |
| **B8 破三连** | 打破三重排比：三个分句→变短长交替；三个比喻→留一个 | 三重排比/三层隐喻 |
| **B9 加插话与自我修正** | 加入"老实说"、"或者说"、"更准确地说" | 无摩擦的流畅流程 |
| **B10 换视角** | 主动/被动换位；从"研究发现"变"数据显示" | 同义替换不改指纹深度 |
| **B11 去连接架** | 删除段落开头的 此外/而且/再者/进一步说 | 段首连接词过多 |

### S4: 词汇微调

| 手法 | 操作 | 修复什么 |
|------|------|---------|
| **C12 培养个人偏好** | 让某些词反复出现（人类writer有偏好词汇） | 词汇均匀分布 |
| **C13 降低形容词密度** | 删除"非常重要的"、"显著的"等强度修饰语 | 形容词过多 |
| **D1 收窄术语** | 把抽象堆叠（范式/生态/格局/体系）换为具体操作 | 抽象名词堆叠 |
| **D2 替换 AI 高频词** | 用 AI 高频词清单做精确替换 | AI 热词 |
| **D3 四字格/三字格句法调整** | 检测并打散中文排比结构 | 中文排比过规整 |

### S5: 校验

1. **改前改后对比**：用 D1–D5 维度分别扫描改前改后文本，确保每个指标在向人类侧方向改善
2. **读出声检查**：朗读改写后的文本，标记所有"读起来怪"的地方
3. **逆向读**：从最后一句读到第一句，检查每句单独是否成立
4. **信息保全检查**：核对信息保全清单（见下方红线），确保数字/结论/专名一个不差
5. **自查清单**：
   - [ ] 所有引用是否真实可核实？
   - [ ] 所有数字是否保留原样？
   - [ ] 是否删除了升华/拔高？
   - [ ] 是否有至少一个反例或限制条件？
   - [ ] 是否有个人的词汇偏好（某个词重复使用了）？
   - [ ] 句子长度是否不均（既有极短句也有长句）？
   - [ ] 段首连接词是否 ≤ 15%？
   - [ ] "的"字密度是否在 0.045–0.065 区间？
   - [ ] 是否有口语化的自我修正或插话？
   - [ ] 哪里像 AI 就会出现在这里（读出声时最不自然的地方）？

### 连接词过度使用信号

来源：ai-patina + humanize-mba-text-skill

段首连接词清单（当这些出现在段首时检测为 AI 信号）：
- 此外 / 另外 / 再者 / 进一步 / 进一步说
- 同时 / 与此同时 / 此外还
- 因此 / 所以 / 因而 / 从而
- 首先……其次……最后（连续三段使用同一模式）
- 综上所述 / 总而言之 / 总的来说 / 总体而言

**目标：段首连接词 ≤ 15%**（即每 20 段最多 3 段以连接词开头）

### 空转大词清单

来源：ai-patina + humanizer-formal

| 类别 | 判定规则 |
|------|---------|
| 主题升华 | ① 结论段出现时代/趋势/浪潮；② 段落末尾拔高 |

| 虚假辩证 | "虽然……但是……"（无实质对立面的伪辩证） |

## 论文专项规则

### MBA论文 5 章节改写要点

来源：humanize-mba-text-skill + humanizer-formal + aigc-humanizer

| 章节 | 核心问题 | 改写方向 |
|------|---------|---------|
| **第1章 绪论** | 宏大叙事开头、研究意义空泛、文献罗列 | 开门见山点明企业+问题；意义具体化；综述按主题组织 |
| **第2章 理论基础** | 教科书定义堆砌、理论过多(5-6个)、理论脱节 | 精选1-2个核心理论；说明选择理由；以应用为导向 |
| **第3章 现状分析** | 资料堆砌关联低、定性为主缺数据、问题笼统 | 聚焦相关背景；具体指标+时间序列；每个问题有衡量指标 |
| **第4章 对策建议** | 建议空泛"加强管理"、缺可操作性、SWOT流于形式 | 明确做什么/怎么做/谁来做；分阶段；预期效果量化 |
| **第5章 结论** | 重复摘要、简单罗列、创新点空泛"填补空白" | 突出核心发现不重复；创新具体；诚实局限 |

### 学术写作"的"字密度

来源：aigc-humanizer

- **自然区间**：0.045–0.065（每 1000 字 45–65 个"的"）
- **AI 侧特征**：密度 < 0.04 或均匀分布（无波动）
- **调节方法**：
  - 密度过低 → 加入定语修饰（"重要的发现"→"这项发现的重要性在于"）
  - 密度过高 → 删除冗余"的"（"重要的关键的决策"→"关键决策"）
- **关键规则**：的/得/地 按功能区分使用，不混用

## 信息保全红线

来源：aigc-humanizer

改写时**绝对不可触碰**的内容：
1. **数字**：百分比、金额、年份、数量——一个数字都不许改
2. **结论**：论点、核心判断、研究结论原样保留
3. **专有名词**：企业名、产品名、人名、地名、标准号——原样
4. **引用**：作者名、年份、来源——不能编造也不能删除
5. **章节编号**：第 X 章、第 X 节——不变
6. **并列项**："第一/第二/第三"的内容不能合并或删除（可以改形式，不能改内容数量）

**操作规则**：
- 改写前冻结信息点清单
- 改后逐条比对信息保全清单
- 任何"信息零新增"——只在原句上改写，禁止凭空增加论据
